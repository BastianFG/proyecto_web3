# KUXO AI // Plataforma de Chatbots Inteligentes para Sitios Web

Solución moderna y de alta conversión para integrar **Chatbots con Inteligencia Artificial** en cualquier página web (WordPress, Shopify, React, HTML5, Wix, Webflow).

---

## 🌟 Características Principales

1. **🤖 Chatbots con IA Conversacional y Calificación de Leads**:
   - Detección de intenciones en tiempo real, respuestas contextuales instantáneas (&lt; 0.8s) y flujo guiado de captura de prospectos (Nombre, Email, WhatsApp, Interés).
   - Simulación de tipeo natural (`...`) y efectos de sonido agradables para interacción de usuario.
   - Plantillas preconfiguradas para diferentes casos de uso:
     - 💼 **Ventas & Leads**: Presentación de planes, demostraciones y captación comercial.
     - 🛠️ **Soporte & Helpdesk**: Resolución de dudas frecuentes, políticas y derivación a asesores.
     - 📅 **Reservas & Agendamiento**: Coordinación de citas y horarios disponibles.
     - ✨ **Base de Conocimientos Personalizada**: Respuestas entrenadas directamente con las preguntas y respuestas de tu negocio.

2. **💻 Simulador de Sitio Web en Vivo**:
   - Marco de prueba interactivo que reproduce la experiencia real de un visitante navegando en tu sitio web con el widget embebido en la esquina inferior.

3. **🎨 Estudio de Personalización Visual (No-Code)**:
   - Configura el nombre del asistente, el avatar, el tono de comunicación y el color de marca (con actualización en vivo de variables CSS).
   - Entrenador de preguntas y respuestas (FAQs) con guardado instantáneo.

4. **⚡ Generador de Código de Inserción (1-Click Copy)**:
   - Snippet listo para pegar en el `<body>` de cualquier sitio web:
     - Etiqueta `<script>` para HTML, WordPress, WooCommerce, Shopify y Wix.
     - Componente para React y Next.js.
     - Código de inserción en `<iframe>`.

5. **📊 Bandeja de Leads & Analíticas en Tiempo Real**:
   - Registro en vivo de todos los contactos capturados por el chatbot con fecha, hora, estado e interés.
   - Opción para exportar la base de datos de prospectos a formato **CSV / Excel**.

6. **💬 Widget Flotante Siempre Accesible**:
   - Botón burbuja flotante en la esquina inferior derecha con indicador de mensajes no leídos y ventana deslizable.

---

## 🛠️ Tecnologías Utilizadas

- **Vite 6** (Servidor de desarrollo y compilador ultrarrápido)
- **Three.js** (Entorno visual ambiental 3D con orbes luminosos y partículas suaves)
- **Web Audio API** (Sintetizador procedural de efectos de sonido para mensajes y clics)
- **Canvas-Confetti** (Animación de celebración al capturar un nuevo lead)
- **Vanilla CSS3** (Tokens de diseño modernos, glassmorphism y microanimaciones fluidas)

---

## 🚀 Instalación y Ejecución Local

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor local
npm start
# o también:
npm run dev
```

La aplicación se abrirá en tu navegador en `http://localhost:5173/`.
