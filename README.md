# Web 3.0 - Future AI

Proyecto interactivo Web 3.0 con efectos visuales dinámicos e interfaz futurista.

## Requisitos previos

- [Node.js](https://nodejs.org/) (versión 18 o superior)
- npm

## Instalación

Instala las dependencias del proyecto:

```bash
npm install
```

## Ejecución en desarrollo

Inicia el servidor local de desarrollo:

```bash
npm start
```
o también:
```bash
npm run dev
```

Esto levantará el servidor local (generalmente en `http://localhost:5173`) y abrirá automáticamente tu navegador.

## Compilación para producción

Para generar los archivos optimizados para producción:

```bash
npm run build
```

Para previsualizar la versión de producción:

```bash
npm run preview
```
